## 操作分级

| 等级 | 典型操作 | 默认处理 |
| --- | --- | --- |
| L0 | 只读发现、清单、差异、审计和Dry Run | 在任务范围内执行 |
| L1 | 本地或临时环境部署 | 明确目标和清理方式后执行 |
| L2 | 专用测试、集成或预生产环境 | 确认所有者、隔离、窗口和恢复后执行 |
| L3 | 标准生产部署、配置、灰度和流量变化 | 必须存在精确目标、批准REL、停止和恢复条件 |
| L4 | 不可逆迁移、破坏性DDL、跨区域流量或永久数据变化 | 需要专项授权、校验、恢复下限和前向修复方案 |

操作等级表达安全要求，不代替项目审批政策。用户要求“发布”不自动覆盖未知生产环境、范围外系统、不可逆数据、真实费用或未计划副作用。

## 执行前检查

确认并记录：目标环境和所有者；账号、租户、集群、命名空间、区域和部署单元；候选版本与摘要；批准范围、窗口和责任人；质量门和例外；依赖、容量和并行发布；数据、契约、配置与流量；监控、告警和基线；停止、回滚、补偿与前向修复；外部通知、费用和业务副作用。

先执行只读查询、计划、差异或Dry Run。工具无法可靠预览时说明限制并缩小首批范围。

## 目标与凭据

- 使用显式、已解析的绝对目标，不依赖模糊“当前环境”、未验证环境变量、宽泛通配符或隐式默认账号。
- 执行前回显安全摘要并核对环境身份；不得输出令牌、密钥、Cookie或完整连接串。
- 使用最小权限和短期凭据；权限过宽或无法确认身份时阻塞执行。
- 目标与批准清单不一致时停止，不自动扩展到相邻服务、集群、区域或租户。

## 数据与副作用

删除、覆盖、缩窄类型、添加强约束、批量回填、重放消息、切换权威写入或触发真实外部动作前，确认精确对象、数量、幂等、备份或恢复、对账、不变量和停止条件。生产备份存在不等于已经验证可恢复；记录恢复能力证据和限制。

不在发布过程中临时创建未设计的数据修复。出现未知数据差异时暂停或进入事故流程。

## 执行约束

- 冻结已批准清单，逐批执行并在每批后验证后置条件。
- 设置超时、并发、速率、批量、资源和费用上限。
- 保留首次失败、实际输出和所有人工动作，不用无限重试掩盖问题。
- 持续观察错误、延迟、资源、队列、数据差异、业务指标和外部调用。
- 只清理由本次发布创建且已确认可删除的临时资源。

## 阻断条件

以下任一情况阻止受影响执行但不阻止只读分析：目标或账号身份不明；候选摘要不匹配；生产授权缺失或含糊；质量门无效且无授权例外；不兼容中间状态未知；凭据过宽；观察入口不可用；停止或恢复方案不可执行；不可逆迁移无校验与前向修复；真实副作用、费用或影响范围未知。
