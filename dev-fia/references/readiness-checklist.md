# 对接就绪检查

## P0：阻塞联调或基线

- 未识别权威机器契约或契约身份无法绑定版本
- 核心场景、调用顺序或最终业务结果未知
- 关键字段、状态、错误或异步最终性存在冲突
- 认证、资源权限或数据范围不明确
- 存量变更未识别消费方、版本组合、发布顺序或回滚影响
- 所需环境不可访问，或样例/Schema 无法用于当前场景
- 开放语义缺口没有责任方和解除条件

## P1：基线前解决或接受

- 次要错误、边界状态、分页排序或缓存语义不完整
- 样例缺少关键分支或未与契约自动核对
- 废弃窗口、观测指标或退出条件不完整
- 联调问题缺少稳定追踪标识或诊断字段

## P2：清晰度和效率优化

- 场景索引、术语、链接或样例可读性不足
- 重复描述可改为权威引用
- 非关键建议与协议事实的标识不够清晰

## 评估规则

| 结论 | 条件 |
| --- | --- |
| `Ready` | 无开放 P0；适用 P1 已解决或由有权限责任方接受；契约、场景、环境和版本可用 |
| `ConditionallyReady` | 无法覆盖全部范围但可安全开始受限联调；条件、范围、责任人和解除标准明确 |
| `Blocked` | 存在开放 P0，或无法判断关键结果是否正确 |

`Ready` 不表示测试通过、验收完成或可发布。`Baselined` 还需要文档责任方确认和证据。

## 前向验证建议

至少覆盖：新增必填字段；新增枚举/未知状态；旧前端对新后端；新前端对旧后端；超时但后端已受理；重复提交；权限和字段脱敏；在途业务跨版本；回滚后新数据继续可用；接口废弃与消费方退出。
