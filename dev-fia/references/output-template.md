# FIA 输出模板

只保留适用章节；机器契约通过稳定引用关联，不复制整份 Schema。

## 1. 对接概览

- `FIA` 编号、版本、状态、`CHG`
- 服务、消费方、业务目标、包含/不包含范围
- 契约身份、实现版本、环境、更新时间
- 当前就绪结论、条件和阻塞

## 2. 契约与通用约定

- OpenAPI/AsyncAPI/Proto/SDL 等权威定位器和摘要
- 基础地址、认证、通用 Header、时间、金额、枚举、空值、追踪标识
- 通用错误、限流、重试和幂等约定

## 4. 场景详细对接

每个场景写清：

1. 目标、参与者、前置条件和完成条件
2. 调用顺序、条件分支、同步/异步边界
3. 操作标识和机器契约引用
4. 请求字段来源、校验责任和敏感信息限制
5. 响应字段消费目的、空值/缺失/未知值含义
6. 状态变化、可执行动作和最终结果取得方式
7. 错误码、展示消息归属、恢复与重复操作结果
8. 权限、数据范围、字段脱敏和审计要求
9. 联调观察点、Trace/请求/操作标识和可脱敏样例

## 5. 兼容、发布与回滚

- 旧/新契约差异和影响场景
- 前后端版本组合矩阵
- 功能开关、灰度、发布顺序和最低可用组合
- 回滚影响、数据/在途业务处理、废弃和退出条件
