# 面向用户的编排视图

按当前任务选用适用项，不为空模板填充内容。视图由专业产物和当前状态生成，无独立编号或批准权威。

1. **目标与范围**：用户目标、已确认约束、完成条件及当前处理边界。
2. **路线与进度**：适用阶段、正在执行或已完成的工作、下一步及责任方；只展示与当前任务有关的阶段。
3. **结果与依据**：链接需求、设计、实现摘要、评审和验证等可读产物，并标明对应版本与关键证据。
4. **风险与阻塞**：未决问题、影响、恢复条件及需要用户作出的业务决定。
5. **完成状态**：区分调度完成、专业结论、验证结果与正式阶段门确认。

内部 `CHG/HOF/LCV/WIT/SWI` 协议对象保存在状态服务或当前会话中；默认不将原始 JSON 写入项目或作为用户交付。状态服务不可用时说明持久化缺口。
