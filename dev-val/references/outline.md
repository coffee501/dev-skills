# 验证结果输出目录参考

向用户呈现就绪诊断、定向验证、缺陷复测、完整验证、专项实验、门禁重算或证据审计时读取本文件。按当前范围选择适用章节；局部结果可合并，不为目录完整生成空内容。`RUN/EVD/DEFECT/GATE/HOF` 的字段与状态由内部协议管理，本文件只规定可读表达。

## 目录

1. [验证结论与适用范围](#1-验证结论与适用范围)
2. [执行结果与证据](#2-执行结果与证据)
3. [失败、例外与未验证范围](#3-失败例外与未验证范围)
4. [验证门判断](#4-验证门判断)
5. [剩余风险与后续行动](#5-剩余风险与后续行动)

## 1. 验证结论与适用范围

先说明被测候选、环境、验证目标、当前结论与适用边界。就绪诊断说明安全门、授权、预期或环境缺口及可继续的只读工作。定向验证没有形成 `GATE` 时明确写“未形成门禁结论”；不得将局部通过推广为完整验证通过。

## 2. 执行结果与证据

按适用性说明已执行的用例或目标、实际结果、预期依据、关键命令或执行入口、证据位置、时间与环境。完整验证用简表逐目标对应 `VAL/DVAL` 与有效证据；局部验证只呈现相关结果。首次失败、重试和清理结果必须可见，原始日志可通过证据定位器复核，不复制到报告正文。

## 3. 失败、例外与未验证范围

列出失败及其证据支持的分类、复现性、影响和责任方；分类不确定时写明未知。说明未运行、跳过、隔离、过期或缺失证据的范围，以及环境、数据、依赖和授权限制。不要把环境或测试缺陷报告为产品通过或产品失败。

## 4. 验证门判断

仅在已有当前 `GATE` 时展开：说明逐 `VAL/DVAL` 结果、总体评估结果、`Suggested/Confirmed` 确认级别及依据、例外或风险接受、重新验证条件。门禁重算应说明相对前次的变化和失效范围。执行数量或通过率只作辅助信息，不替代目标聚合规则；验证门结果不表示外部交付批准。

## 5. 剩余风险与后续行动

说明剩余风险、需要补充的执行或证据、重新验证触发条件和下一责任方。正式交接仍使用内部 `HOF`；面向用户只概述交接事项和解除阻塞条件，不展示原始协议字段。

完整验证报告来源于指定版本 `GATE` 及其引用；没有 `GATE` 的执行摘要来源于当前 `RUN/EVD/DEFECT`。两者都是无独立状态的只读视图，须标明实际来源，来源变化后更新，不自行确认或改变门禁结论。
